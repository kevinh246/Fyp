# Next Track
NextTrack is a privacy focused music recommendation API that is designed to generate the next- track music suggestion by using user supplied parameters.

## Steps to run the project
1. Clone this repository to your local machine.
2. You need to have Node JS installed on your local machine.
3. Run ``npm install``. This will install all of the project dependencies.

### Running the API
1. ``node index`` to run the API
2. A local webserver will be started on port 3000
3. You can access the API at localhost:3000/api/recommendation

### Running tests
1. ``npm test`` to run all unit tests
